How the test works.

  1. Two to three versions

    You write 2 to 3 versions of one idea. Only the one thing you chose differs between them.

  2. One card per swiper

    Flagsmith randomly assigns each swiper exactly one version. They never see the others, so there is no order bias.

  3. Reward claims are the result

    A positive answer offers your launch reward in exchange for an email. The version that earns the most claims wins.

  4. Your waitlist

    Every claim joins one waitlist. Flagsmith calls a winner only with at least 50 people per card and a 95% chance to beat the control. You approve before anything ships.
